# Pillbox - 3D Printable Pill Organizer

## Project Overview
A two-part 3D-printable pill organizer with a sleeve container and sliding drawer with 3 compartments. Designed for credit card-sized portability with smooth operation and a friction-lock mechanism.

### Dimensions
- Overall: 86 x 54 x 19 mm (credit card size, 0.75" height)
- Sleeve: 86 x 54 x 19 mm (2.0mm walls, closed bottom)
- Drawer: 84 x 17 x 16 mm (1.5mm walls, pulls from 54mm edge)
- Drawer clearance: ~1.0mm on sides
