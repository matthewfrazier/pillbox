# Pillbox Drawer Motion - Animation Guide

## Motion Sequence
The drawer slides smoothly out from the short edge (54mm side) of the sleeve.

### Frame 1: Fully Inserted (At Rest)
- Drawer seated inside sleeve
- Pull grip flush/integrated with drawer
- Compartments internal and hidden
- Ready for storage/carry

### Frame 40: Halfway Out
- Drawer begins to separate from sleeve
- Pull grip becomes visible
- Friction bump engagement point visible
- Drawer can be seen sliding smoothly

### Frame 80: Fully Pulled Out
- Drawer completely separated from sleeve
- 3 compartments clearly visible inside drawer
- Pull grip fully extended for hand grasp
- Drawer can be accessed or refilled
- Drawer and grip form single unit

## Design Features Demonstrated

### Interior Compartments
✓ 3 flat divider walls running lengthwise (84mm direction)
✓ Compartments are rectangular, not curved
✓ Each compartment: ~28mm wide x 84mm long x ~15mm deep
✓ Dividers: 1.0mm thick, flat surfaces
✓ Spacing is equal for balanced storage

### Smooth Motion
✓ Drawer slides from short edge (54mm)
✓ Clearance: ~1.0mm on sides for smooth operation
✓ Friction bump on side engages for slight resistance
✓ Pull depth: 17mm max (compact, pocket-friendly)
✓ Motion is linear and unobstructed

### Pull Grip Design
✓ Tab shape on long edge (84mm direction)
✓ Centered position for thumb access
✓ 76 x 7 x 3 mm dimensions
✓ Rounded edges for comfort
✓ Protrudes when drawer is inserted (accessible)

## Compartment Specifications
- Type: 3 separate compartments
- Material: integral dividers within drawer
- Width each: ~28mm
- Length: 84mm (full drawer length)
- Depth: ~15mm (fits standard pills)
- Walls: 1.0mm thick (3D print compatible)
- Interior surfaces: smooth and flat

**Note on Geometry:**
The compartment dividers are FLAT rectangular walls, not curved. Any curved appearance in the viewport is due to beveled edges (1.0mm radius) which are necessary for 3D printing comfort and durability. The actual functional surfaces (interior compartment walls) are flat.

## Assembly & Use
1. Drawer fully inserted = compact portable form
2. Pull grip to slide drawer out smoothly
3. Access all 3 compartments when drawer is open
4. Friction bump provides slight resistance (prevents accidental sliding)
5. Push drawer back in to close

## 3D Print Notes
- Compartment dividers: 1.0mm walls (printable on all FDM/resin printers)
- Smooth interior surfaces for easy pill insertion/removal
- Drawer slides with ~1.0mm clearance (tight enough for friction, loose enough for smooth operation)
- Friction bump: 1.5mm height (gentle engagement)
